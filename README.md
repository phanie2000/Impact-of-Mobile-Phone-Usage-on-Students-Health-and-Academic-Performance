# Impact of Mobile Phone Usage on Students' Health and Academic Performance

This project investigates the relationship between mobile phone usage patterns and students' perceived health and academic performance using survey data analyzed in **R**.

---

## Overview

Mobile phones have become an essential part of students' daily lives, supporting communication, learning, and access to information. However, excessive or inappropriate usage may contribute to health concerns, reduced attention span, and poorer academic outcomes. This project analyzes a Kaggle survey dataset using R to examine students' mobile phone usage behaviors, educational use, perceived academic performance, and health outcomes. Following data cleaning and exploratory data analysis (EDA), descriptive statistics and Fisher's Exact Tests were performed to identify significant associations between mobile phone usage characteristics and health and academic performance.

### Tools & Technologies

* **Programming Language:** R
* **Data Source:** Kaggle
* **Analysis:** Data Cleaning, Exploratory Data Analysis (EDA), Descriptive Statistics, Fisher's Exact Test

### Dataset

The dataset was obtained from **Kaggle** and contains information on:

* Student demographics
* Mobile phone characteristics
* Daily usage patterns
* Educational use of mobile phones
* Perceived academic performance
* Health-related symptoms and precautions

### Key Findings

* Higher mobile phone usage and increased distraction were associated with poorer perceived academic performance.
* Students who primarily used mobile phones for educational purposes generally reported positive learning benefits.
* Frequent mobile phone use was associated with increased reports of health-related symptoms.
* Fisher's Exact Tests were used to examine statistical associations between categorical variables.
